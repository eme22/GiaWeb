# Pokédex Linktree — Edición Gia 🌸

Un sitio web personalizado tipo **Linktree** con temática Pokédex retro en color rosa, diseñado especialmente para **Gia**.

---

## ✨ Características

- 🎮 **Diseño Consola Pokédex**: Interfaz visual estilo Game Boy / consola portátil con pantalla biselada y detalles retro.
- 🔗 **Enlaces a Redes Sociales**: TikTok, Instagram, WhatsApp y botones desactivados para futuras plataformas (YouTube, Twitch).
- 🔊 **Sonidos Retro Inteactivos**: Efectos de sonido sintetizados mediante Web Audio API al presionar botones y navegar.
- 💖 **Pokémon Interactivos**: Sprites de Pokémon Tipo Hada (Sylveon, Diancie, Alcremie y Tapu Lele) que despliegan una ficha de datos y sonido original al hacer clic.
- 📱 **Diseño 100% Responsivo**: Adaptado perfectamente para celulares y escritorios.
- 📋 **Panel de Créditos Desplegable**: Panel flotante contraído por defecto con información de desarrollo y tecnologías.

---

## 🛠️ Tecnologías Usadas

- **HTML5** & **CSS3 Vanilla** (Variables CSS, Flexbox, Grid, SVG)
- **JavaScript (ES6+)**
- **Web Audio API** (Sintetización de sonidos retro)
- **Google Fonts** (*Press Start 2P*, *Pixelify Sans*, *VT323*)
- **PokéAPI** (Datos y audio de los Pokémon)
